# Соглашение об иллюстрациях

## Геометрия

Одна единица viewBox равна 1 pt в печати. Фигура включается в натуральную величину:

```latex
\includefigure{assets/figures/chXX-name/figure}
```

- ширина холста 385 = `\textwidth`; узкая фигура берёт меньшую ширину, шире нельзя;
- высота холста до 272 = `.45\textheight`; не помещается - фигура делится или уходит в таблицу;
- корневой `<svg>` несёт `width` и `height` в pt, равные viewBox: `viewBox="0 0 385 144" width="385pt" height="144pt"`;
- размеры в `\includefigure` не задаются: масштабирование ломает кегль и толщины.

Фигура без pt в `width` - legacy: включается `\includefiguresvg` с масштабом под полосу, линтер её не проверяет. Правка legacy-фигуры переводит её в канон целиком.

## Жанр и инструмент

- sequence (участники по горизонтали, время сверху вниз) - генератор на `scripts/figures/_seq.py`: перевод строки в имени или подзаголовке участника даёт многострочную шапку, `lanes=` задаёт ширину полосы участника;
- byte-map и bit-map (hex-дамп, байты, биты с легендой) - генераторы `scripts/figures/gen_*.py`, битовая раскладка байтов - через `scripts/figures/_bitgrid.py`;
- топология, state machine, timeline, decision tree, график - Inkscape по шаблону `assets/inkscape-template.svg`;
- матрица сравнения (N сущностей по M атрибутам) - таблица LaTeX по канону `src/styles.tex` (`\tablesetup`, `\headrow`, `\rowsep`, `\tablenote`), не SVG;
- линейный нарратив, который уже идёт прозой, - без фигуры.

### Запрет: школьная блок-схема

Прямоугольники со скруглением, связанные стрелками в линейный или разветвлённый flow, не несут информации сверх нумерованного списка в прозе.

Признаки:

- 3-8 одинаковых блоков с короткой подписью ("Покупка", "Авторизация", "Расчёт");
- стрелки собирают блоки в цепочку или дерево с ветвями "да/нет";
- подпись блока повторяет слово из того же абзаца прозы.

Замена - жанр из списка выше: sequence для обмена сообщениями, state machine для состояний с событиями на рёбрах, топология для взаимного расположения компонентов, decision tree с содержательными условиями на рёбрах. Если ни один жанр не подходит, фигура не нужна.

## Цвет

| Имя     | Hex       | Роль                                                  |
|---------|-----------|-------------------------------------------------------|
| Ink     | `#1A2030` | основной текст; для линий не используется             |
| Muted   | `#5C647A` | вторичный текст, нейтральные связи, каркас            |
| Panel   | `#E8ECF7` | заливка нейтрального блока и панели                   |
| Soft    | `#F5F7FD` | фон зоны                                              |
| AccentA | `#4E63D9` | сторона A                                             |
| AccentB | `#7759D6` | сторона B                                             |
| Good    | `#2F8B67` | оценка: ok, разрешено, штатный путь                   |
| Warn    | `#B8821C` | оценка: осторожно, условно, fallback                  |
| Bad     | `#C15462` | оценка: нельзя, отказ, ошибка                         |

Других цветов нет, кроме `#ffffff` для негативного пространства и подложки подписи. Цвета продублированы в `src/styles.tex` и `scripts/figures/_common.py`.

- блок и связь по умолчанию нейтральные: Panel с обводкой Muted, связь Muted;
- AccentA и AccentB различают две стороны одной схемы (эмитент и эквайер, плательщик и получатель); третьей стороны нет, больше двух сторон - декомпозиция;
- Good, Warn, Bad только оценивают исход; цвет без оценки или стороны за ними не закрепляется;
- заливка тона - сплошной цвет с `fill-opacity="0.15"`, у Warn `0.18`; обводка тем же цветом без opacity; Panel и Soft заливаются без opacity;
- цвет не единственный канал (WCAG 1.4.1): оценку дублирует слово, сторону - подпись.

### Заливки byte-map

В плотной byte-map смежные ячейки разных типов при opacity 0.15 сливаются (delta E около 3 между AccentA и AccentB, неразличимы при дальтонизме), поэтому тип кодируется светлотой. Уровни заданы в `scripts/figures/_common.py`:

- `TIER_PANEL` (1.0, сплошной `PANEL`) - самый светлый, нейтральный лист;
- `TIER_LIGHT` (пара `0.22`/`0.32` для `ACCENT_A`) - светлый тир, пара чередует смежные поля одного типа через `zebra(TIER_LIGHT, alt)`;
- `TIER_LIGHT_MID` (`0.27`) - образец светлого тира в легенде;
- `TIER_NEUTRAL` (`0.42`, `MUTED`) - нейтральный тёмный тир;
- `TIER_DARK` (`0.55`, `ACCENT_B`) - тёмный тир.

Лестница даёт delta E не меньше 8 между типами под дейтеранопией при контрасте текста не ниже 7:1. Нецветовой признак дублирует цвет: тёмная кромка на байтах LL-префикса, слово типа в легенде. Самоподписанные блоки-сегменты (`secure-messaging`, `emv-cert-recovery`) живут по общему правилу 0.15.

## Текст

Шрифт `font-family="Inter, -apple-system, BlinkMacSystemFont, 'Helvetica Neue', Arial, sans-serif"`, текст остаётся текстом, без обводки и без перевода в кривые.

- `font-size="9"` bold - заголовок секции или панели;
- `font-size="8"` - подпись блока (bold для имени), подпись сообщения;
- `font-size="7"` - подзаголовок блока, пометка, подпись связи, цвет Muted.

Других кеглей нет: подпись к рисунку набрана 9 pt, текст фигуры не мельче 7 pt и не крупнее подписи. Unicode-операторы (U+2295, U+2297) ломают PDF-экспорт Inkscape, в SVG пишется `XOR`, `AND`.

## Линии и стрелки

- `stroke-width="0.5"` - рамка зоны или панели, линия жизни, сетка;
- `stroke-width="0.75"` - контур блока;
- `stroke-width="1"` - связь и стрелка;
- `stroke-dasharray="3,2"` - ответ, асинхронная или необязательная связь, необязательный блок; других паттернов нет;
- `rx="3"` - скругление блока.

Стрелка - `<marker>` из `defs`: `arr-AccentA`, `arr-AccentB`, `arr-Good`, `arr-Warn`, `arr-Bad`, `arr-Muted` и их `-s`-варианты для `marker-start`. Имя маркера - имя цвета, цвет линии и маркера совпадает. Маркер задан в единицах толщины линии: при stroke 1 стрелка 5 pt.

## Генератор

Скрипт `scripts/figures/gen_<name>.py` импортирует палитру, геометрию и helpers из `_common.py` (`svg_header_pt`, `box`, `arrow`, `markers`, `text_width`), жанровую вёрстку - из `_seq.py` и `_bitgrid.py`. Данные фигуры (участники, сообщения, поля) описываются в скрипте, координаты считает жанр. Источник данных цитируется в docstring ключом `assets/bibliography.bib`.

```bash
python3 scripts/figures/gen_<name>.py   # SVG
make svg                                # линтер + PDF
```

SVG генерируемой фигуры руками не правится: правка теряется при следующем запуске.

## Inkscape

- старт - `File / Open` на `assets/inkscape-template.svg`, затем `File / Save As` в каталог главы; новый документ Inkscape приносит чужие шрифт, единицы и обводку;
- холст меняется только по высоте, `Document Properties` в pt; ширина 385 или меньше;
- блоки, стрелки и подписи копируются из образцов шаблона, образцы затем удаляются; цвет вводится hex из таблицы, Color Picker по чужим SVG приносит пастель вне палитры;
- стрелка Inkscape по умолчанию (`Arrow1Lend`) заменяется маркером `arr-*` из `defs` шаблона;
- один блок - одна группа (`Ctrl+G`), одиночная группа из одного элемента разгруппировывается;
- сохранение - `Plain SVG`: атрибуты `sodipodi:*` и `inkscape:*` линтер отвергает.

## Проверка

`make figlint` (и `make svg` перед конвертацией) прогоняет `scripts/figures/lint_svg.py`: равенство pt и viewBox, габариты холста, палитра, кегли, толщины, пунктир, opacity, маркеры, выход текста за холст, атрибуты Inkscape. Pre-commit (`make init`) проверяет проиндексированные SVG тем же скриптом. `lint_svg.py --strict` дополнительно перечисляет legacy-фигуры и падает на них.

`.tex` подключает PDF, не SVG: после правки SVG нужен `make svg`.
